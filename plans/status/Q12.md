## Notes for dependents

- Q13: the seed 2 and seed 3 runs found 13 cases whose presentation fails the independent
  security assertions on the reference and the port alike (the port matches Rails byte for byte).
  `plans/fuzz-run-2.md` describes them only in outline, since this repository is public; the
  bodies are reproducible with the fuzzer (seeds 2 and 3) and need a private report upstream.
- `Campfire.RichText.Html.LegacyHtmlParser` is `Nokogiri::HTML4::DocumentFragment.parse`
  (libxml2 2.13.9's legacy parser). Use it wherever Rails calls `Nokogiri::HTML.fragment` or
  `Nokogiri::HTML4`; `HtmlParser` is HTML5 only. `Html4Entities` moved to `Campfire.RichText.Html`.
- `DifferentialFuzzTests.Record_regression_cases` (`CAMPFIRE_FUZZ_REGRESSIONS=<findings.jsonl,...>`)
  re-records the regression corpus from a run's findings.
