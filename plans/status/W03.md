## Notes for dependents

- How to declare templates, build the `View` and translate helper calls:
  `src/Campfire.Web/Helpers/README.md`.
- **Library** (`Campfire.Web.Helpers.Rails`, global using in Campfire.Web): `HtmlOptions` (ordered
  Ruby-hash options), `Tag` (`tag.*`), `TagHelper` (`tag`, `content_tag`, `token_list`,
  `TagOptions`), `OutputSafety` (`raw`, `safe_join`, `+`), `RubyValues` (`to_s`, `to_json`,
  `blank?`, escaping), `RecordKey`/`RecordIdentifier` (`dom_id`, `dom_class`, `to_gid_param`),
  `FormModel`/`FormBuilder`, `TurboStreamTags` (`turbo_stream.*`).
- **On `View`**: `ContentFor`/`Yield`/`Render`/`Capture`, `ImageTag`, `ImagePath`, `ImageUrl`,
  `AssetPath`, `StylesheetLinkTagAll` and `LinkHeader`, `JavascriptImportmapTags`,
  `CsrfMetaTags`, `CspMetaTag`, `TokenTag`, `LinkTo`, `ButtonTo`, `MailTo`, `BackUrl`,
  `TextFieldTag`, `HiddenFieldTag`, `CheckBoxTag`, `ButtonTag`, `FieldId`, `FieldName`, `FormWith`,
  `TurboFrameTag`, `TurboStreamFrom`, and the app's helpers: application (`PageTitleTag`,
  `CurrentUserMetaTags`, `CustomStylesTag`, `BodyClasses`, `LinkBack`, `LinkBackTo`), accounts,
  broadcasts, cable, clipboard, drop target, emoji (`Reactions`), forms (`AutoSubmitFormWith`), QR
  code, rich text (`RichTextDataActions`, `MentionPromptTag`), rooms (all but
  `room_display_name`), searches, time (`LocalDatetimeTag`), translations, users, users/avatars,
  filter, profiles, sidebar, version, rooms/involvements, and messages' tag helpers (`MessageAreaTag`,
  `MessagesTag`, `MessageTag`, `MessageTimestamp`, `MessageAuthorTitle`).
- **Templates**: `ApplicationLayout(w, page)`, `Lightbox(w)`, `ActionTextContentLayout(w, content)`,
  `MailerLayout(w, body)`.
- Block helpers return `IHtml` and write the block straight into the output. Rails captures the
  block and, when its output is blank, uses the block's value instead (usually nil, so an empty
  element); a C# block has no value, so a whitespace-only block renders its whitespace. No
  reference view yields a blank block to these helpers.
- A call with options but no content needs the parameter name, `Tag.Div(options: new() { … })`,
  since `new()` also converts to the block overload's `Action`.
- **Shared file touched**: `src/Campfire.Web/Campfire.Web.csproj` (F02's, done) now compiles
  `Views/**/*.erb.cs` as template `AdditionalFiles`, as the W04 notes asked.
- `Helpers/GlobalUsings.cs` makes `Campfire.Templates` and `Campfire.Web.Helpers.Rails` global
  usings, so feature files must not repeat them (IDE0005 fails the build).

## Known gaps

- Not ported, because they need other lanes' code: `message_presentation` and
  `Messages::AttachmentPresentation` (M01 owns `Helpers/Messages/`), `editable_body` (Action Text
  attachments, R03), `room_display_name` (needs a direct room's users; D02/M lane), the
  `form.rich_text_area` Lexxy editor field (M02 can add it as an extension method on
  `FormBuilder`), and `cache` (fragment caching renders the same bytes uncached).
- Placeholders other than strings (`placeholder: true`, translated), `object[]` auto-indexed field
  names and `multiple` check boxes throw `NotSupportedException`; the app uses none of them.
- `polymorphic_path` isn't modeled: `form_with model:` needs its URL passed explicitly.
- `layouts/mailer.text.erb` isn't ported: the app sends no mail.
