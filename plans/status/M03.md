## Notes for dependents

- **Ownership moves** (in `plans/tasks.yaml`): M03 took `rooms/involvements/_bell*` from M07,
  `accounts/_invite*` from A03, `pwa/_*` from A08 and `layouts/turbo_rails/` from W03, since the
  room page renders them. W03 keeps `layouts/*` and `layouts/action_text/`.
- **Turbo frame layout:** turbo-rails renders any action in `layouts/turbo_rails/frame` for a
  Turbo frame request unless the controller declares its own layout (MessagesController's
  `layout false, only: :index` does, so its pages keep the application layout).
  `View.TurboRailsFrameLayout` is there for other page controllers.
- **Blank captures:** ActionView's `capture` returns the block's last text chunk, not the
  whitespace, when the block's output is blank, so an empty room's `messages_tag` holds just
  "\n". `View.CaptureOrLastText` emulates it for `rooms/show`; W03's streaming `ContentTagBlock`
  doesn't, which may matter for other `tag.x do … end` blocks that can render blank.
- `rooms#destroy`'s `ensure_can_administer` is in the chain; M07 binds and implements destroy.
