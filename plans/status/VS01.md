## Notes for dependents

- B02 can treat this path as real: Rails cookie → C# room HTML → create → cable payload to a
  second member → Rails reads the C# database. Do not publish numbers. Every measured response
  still has to be replay-equal first.
- The application entry the tests use is `WebApp.HandleAsync`. It installs the app on the
  request, then the ordered router. Controllers call `WebApp.Of` and throw if the request did
  not come through it.
- `MessageLifecycle.Create` is the write both the HTTP create action and the Rails rollback
  use. The rollback's row is `client_message_id = csharp-1`.
