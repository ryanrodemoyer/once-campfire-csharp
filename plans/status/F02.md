## Notes for dependents

- **Projects.** Ten libraries under `src/` and one xUnit v3 project per library under
  `tests/<Project>.Tests/`, all in `Campfire.slnx`. `Campfire.Templates*` from the layout is two
  projects: `Campfire.Templates` (runtime) and `Campfire.Templates.Generator` (the W04 source
  generator, `netstandard2.0`, loaded by Web as an analyzer).
- **Edges.** RailsCompat ← Data ← RichText, Storage ← Cable, Jobs ← Web ← Server, plus
  Templates and Templates.Generator → Web. Cable and Web reference the ASP.NET Core shared
  framework; Server uses `Microsoft.NET.Sdk.Web` and builds `campfire.dll`.
- **Shared settings** live in `Directory.Build.props`: `net10.0`, nullable, implicit usings,
  warnings as errors, `AnalysisMode=Recommended`, code style enforced on build. Every
  `*.Tests` project gets xUnit v3, the VSTest adapter and `using Xunit;` from there, so its
  csproj only lists project references. `GenerateDocumentationFile` is on only so IDE0005
  (unused usings) runs on build; CS1591 is suppressed.
- **Packages** are versioned centrally in `Directory.Packages.props` with transitive pinning.
  Add a `PackageVersion` there and a versionless `PackageReference` in the project.
- **SDK.** `global.json` pins `10.0.100` with `rollForward: latestFeature`. Ubuntu 24.04's
  `dotnet-sdk-10.0` package (10.0.112) satisfies it; the Microsoft install script hosts were
  blocked from the cloud session, which F03's `bin/setup` will need to account for.
- **Server.** `Campfire.Server.Program.Build(args)` returns a slim `WebApplication` with one raw
  `RequestDelegate`: `/up` → 200, anything else → 404. W01's router replaces the delegate; the
  `/up` response body is not yet matched to `Rails::HealthController`.
- **Style.** `.editorconfig` enforces file-scoped namespaces, omitted default access modifiers,
  camelCase private fields without prefixes, PascalCase static readonly fields, and no unused
  usings. Tests may use underscores in names and skip `ConfigureAwait`.
