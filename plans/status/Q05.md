## What landed

- `parity/cable/client.py`: Raw WebSocket client implementing RFC 6455 masking, HTTP 101 upgrade handshake with `actioncable-v1-json` subprotocol, ping/pong frames, close handshakes, and Action Cable command transmission (`subscribe`, `unsubscribe`, `message`).
- `parity/cable/normalizer.py`: Action Cable frame normalizer based on `reference-rust/parity/capture/network.ts`: ignores heartbeat pings (`type: ping`), canonicalizes channel identifiers with sorted JSON keys, normalizes HTML fragments inside Turbo Streams payloads, and normalizes disconnect metadata.
- `parity/cable/diff.py`: Structural diff engine for Action Cable frame sequences that compares frame counts, types, identifiers, message payloads, and disconnect reasons / reconnect flags.
- `parity/cable/defects.py`: Defect injection and verification module with 7 planted defect kinds (`wrong-outcome`, `missing-message`, `extra-message`, `modified-payload`, `wrong-disconnect-reason`, `wrong-reconnect-flag`, `missing-lag-disconnect`) to ensure differences are caught.
- `parity/cable/scenarios.py`: Full inventory of channel scenarios and golden vectors for:
  - `HeartbeatChannel`: subscription confirmation
  - `PresenceChannel`: member confirmation, `present`/`refresh` actions, non-member rejection, non-numeric room rejection
  - `ReadRoomsChannel`: subscription confirmation, read room notifications
  - `RoomChannel`: member confirmation, non-member rejection, missing id rejection
  - `RoomMessagesChannel`: signed stream name confirmation, forged/tampered rejection, missing stream rejection
  - `TypingNotificationsChannel`: member confirmation, peer typing start/stop broadcast, non-member rejection
  - `UnreadRoomsChannel`: subscription confirmation, subscribed action, unread fanout broadcasts
  - `Turbo::StreamsChannel`: signed stream confirmation, Turbo Stream `<turbo-stream>` frame delivery, forged stream rejection
  - `ApplicationCable::Channel`: base channel subscription confirmation matching reference
  - `(connection)`: unauthenticated connection rejected with `reason: "unauthorized", reconnect: false`
  - `(revocation)`: room membership revocation (`remote`, `reconnect: true`), user deactivation (`remote`, `reconnect: false`), and user ban (`remote`, `reconnect: false`)
  - `(lag)`: queue overflow disconnect with `reason: null, reconnect: true`
- `parity/cable/Server.cs`: Standalone C# candidate server hosting Kestrel with `/cable` mounted, `RevocationGuard`, `DomainSeams`, and SQLite database.
- `parity/cable/run`: Command-line executable harness supporting `--replay`, `--selftest`, `--channel`, `--report`, and live comparison.
- `parity/cable/test_cable.py`: 26 offline unit tests covering RFC 6455 framing, normalizer, diff engine, planted defect detection, and golden vector verification.
- `parity/cable/results.json`: Execution results demonstrating 19/19 scenarios passing with 100% parity against reference vectors.
- `parity/cable/README.md`: Harness documentation and usage instructions.
