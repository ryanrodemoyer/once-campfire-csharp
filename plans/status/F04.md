## Notes for dependents

- `Campfire.Web.Assets.AssetBundle`: `Build(AssetSources, builtAt)` or `Load(directory)` (the
  output of `bin/build-assets`, default `artifacts/assets`). It exposes `AssetPath(source)`
  (ActionView's `asset_path` over the manifest; null for a missing asset where Propshaft raises),
  `DigestedPath(logicalPath)`, `StylesheetPaths` (Propshaft's `all_stylesheets_paths`, for
  `stylesheet_link_tag :all`), `ImportmapTags` (`javascript_importmap_tags`, ready to write into
  the layout), `ImportmapJson`, `Manifest`, `Files` and `LastModified`.
- `Campfire.Web.Assets.StaticFiles`: ActionDispatch::Static. `Serve(StaticRequest)` is the pure
  version; `TryServeAsync(HttpContext)` writes the response and returns false to fall through to
  the router. Put it first in the pipeline, as Rails does.
- W03 still owns the `stylesheet_link_tag` markup and the `link` preload header that goes with it;
  the reference's expected output is `reference-rust/crates/assets/tests/reference/
  stylesheet_link_tag_all.html` and `link_header.txt`.
- The reference sends `Cache-Control: public, max-age=2592000` for every static file, digested or
  not: the second `public_file_server.headers` assignment in `production.rb` replaces the
  immutable one-year one. The card asked for far-future immutable caching; matching Rails wins.
- `assets/overrides/` is empty: the C# port keeps Rails' CSRF headers, so none of the Rust port's
  overrides apply. `AssetBundleTests.The_port_overrides_nothing_yet` fails if one is added
  without teaching the golden tests which files may differ.

## Known gaps

- `public/assets/.manifest.json` has the reference's entries and byte length but not its key
  order, which is Propshaft's `readdir` order on the build machine and so differs between
  filesystems for Rails too. Nothing reads its order. X01 can list it under README known
  differences if it wants it recorded.
- Rack::Files sends each file's own mtime as `last-modified`; the bundle uses one build time for
  every file (`SOURCE_DATE_EPOCH` when set).
