## Notes for dependents

- `UsersAvatarsController` (`src/Campfire.Web/Controllers/Users/AvatarsController.cs`) is bound
  to `users/avatars#show` and `#destroy` in `AvatarsRoutes.cs`.
- `UsersAvatarsController.DetachAvatar(tx, userId, now)` is `user.avatar.destroy`: deletes the
  attachment and touches the user; the blob is left for `ActiveStorage::PurgeJob`, as A03's logo.
  The profile task (`users/profiles#update`) can reuse it.
- `View.UsersAvatarsShow(w, user)` renders `users/avatars/show.svg` with no layout.
- Rails adds the action template's digest to the ETag (`EtagWithTemplateDigest`) only when the
  request's formats take SVG (`*/*`, `image/svg+xml`, `.svg`); browsers' image `Accept` headers are
  browser-like, so they get the plain user ETag. `Freshness.Template` carries the digest.
- Test classes for Users::* controllers can't use the namespace
  `Campfire.Web.Tests.Controllers.Users`: it hides `Campfire.Data.Queries.Users` from
  `ByBotsReplayTests`. These live in `Controllers/Avatars`.
