## What was built (`src/Campfire.Jobs/OpenGraph/`)

- `OpenGraphFetch`: `Opengraph::Fetch`. GET or HEAD through `RestrictedHttpHandlers.OpenGraph`
  with the guard's address pinned (`RestrictedHttpHandlers.PinnedAddress`). Any 3xx is a redirect;
  its `Location` is parsed with `RubyUri`, must be http(s), and is resolved through the guard
  again. More than 10 responses raise `TooManyRedirectsException`. A document must be a 200 whose
  `Content-Type` is exactly `text/html` (Net::HTTP's `content_type`: stripped but not downcased),
  with `Content-Length` at most 5MB; reading stops once more than 5MB has been inflated. Requests
  carry Net::HTTP's `Accept`, `Accept-Encoding`, `User-Agent: Ruby` and `Host` byte for byte. The
  handler's automatic decompression is turned off because it rewrites `Accept-Encoding`, so gzip
  and deflate are inflated here. Timeouts are Net::HTTP's 60s: for the connect, the response head
  and each body read.
- `OpenGraphLocation`: `Opengraph::Location`. `IsValidAsync`, a memoized `ResolvedIpAsync`,
  `ReadHtmlAsync` (skips `FILES_AND_MEDIA_URL_REGEX`) and `FetchContentTypeAsync`. Fetch failures
  are rescued to null as Rails rescues them; cancellation by the caller is not.
- `LegacyHtml` and `Html4Entities`: the part of `Nokogiri::HTML` (libxml2's HTML4 parser) that
  `Opengraph::Document` reads. Bytes are decoded as UTF-8 with invalid bytes read as Latin-1, then
  every `<meta>`'s attributes are extracted, plus `meta_encoding`. Ported from the Rust port's
  probed scanner.
- `OpenGraphDocument`: `opengraph_attributes`.
- `OpenGraphMetadata`: `Opengraph::Metadata` with `Fetching`, `valid?` (`strip_tags` then
  `sanitize` on title and description) and `to_json` (instance variables in assignment order, plus
  `context_for_validation` and `errors`, via `RailsJson.Encode`).

## Notes for dependents

- M09 (`UnfurlLinksController`): `await OpenGraphMetadata.UnfurlAsync(fetch, url, ct)` returns
  the JSON body for `render json:` (200, `application/json`), or null for `head :no_content`. It
  throws `OpenGraphRaisedException` (with `RubyClass`) wherever Rails raises a 500:
  `URI::InvalidComponentError` for `mailto:foo`, `NoMethodError` when fxtwitter can't be read, and
  `ArgumentError` past Gumbo's limits. A missing or blank `url` param (400) is the controller's
  job.
- Build one `OpenGraphFetch(PrivateNetworkGuard.System)` and share it. It owns a handler, so
  dispose it at shutdown. Set `Warn` to receive the `Rails.logger.warn` lines.
- Q08 (opengraph embeds) can reuse `OpenGraphLocation` and `OpenGraphFetch`.

## Known gaps

- Tests live in `tests/Campfire.Jobs.Tests/OpenGraph/`, and `tests/Campfire.Jobs.Tests` now
  references `tests/Campfire.Vectors`. Both are outside this card's `owns`, as they were for I04.
  `src/Campfire.Jobs/OpenGraph/InternalsVisibleTo.cs` exposes the `strip_tags`/`sanitize` helpers
  to those tests.
- HTTPS goes through the same `SocketsHttpHandler` TLS path the I04 handler tests use, but no test
  here runs over TLS: the scripted server speaks plain HTTP, like the oracle's. The reference's
  https test URLs are http in `OpenGraphFetchTests`.
- Like Rails there is no overall deadline on an unfurl, only per-step 60s timeouts. The Rust port
  added a 10s deadline and a concurrency cap as a deliberate difference; adding them here would
  be M09's decision and needs a README "Known differences" entry.
