## Notes for dependents

Namespace `Campfire.RailsCompat.Params`:

- `ParamBuilder.FromQueryString(bytes|string)` is `request.GET`. `ParamBuilder.FromPairs` and
  `ParamBuilder.FromJson` are also public.
- `RequestBody.ParseAsync(method, contentType, contentLength, body, tempDirectory?)` is
  `request.POST`.
  - Pass the method **on the wire**, not the overridden one.
  - It returns a `ParsedBody` with `Raw` (`raw_post`; empty for multipart) and `Params`. `Params`
    throws the stored `ParamException` when there was one, matching Rails' lazy raising.
  - The caller must dispose the `ParsedBody`, which deletes upload temp files (Rack's
    `TempfileReaper`).
- `MethodOverride.Resolve(method, contentType, parsedBody, xHttpMethodOverride)` is
  `Rack::MethodOverride`. W01 should parse the body once, before routing, and hand the
  `ParsedBody` on.
- Error mapping for W01:
  - `ParamException.StatusCode`: 400, or 406 for `InvalidMimeType`.
  - `ParameterMissingException`: 400.
  - `RequestBodyTooLargeException`: 413.
  - `InvalidOperationException` from the multipart parser stands for the `NoMethodError`s Rack
    raises on some malformed parts (Rails answers 500).
- Param values are Ruby-shaped `object?`: `string`, `null`, `bool`, `long`, `BigInteger`, `double`,
  `UploadedFile`, `List<object?>` or `ParamHash` (insertion-ordered).
- `params.require(:x).permit(:a, settings: {})` is
  `p.RequireHash("x").Permit("a", PermitFilter.AnyHash("settings"))`.
- Path parameters, merging GET/POST/path into `params`, and JSON `wrap_parameters` are
  controller-level (W01).

## Known gaps

These differences from Rails need README "Known differences" entries, which this task doesn't own:

1. Non-multipart bodies are buffered up to 16 MB (`RequestBody.MaxBufferedBody`), and anything
   bigger is a 413. Rails reads any size. The same limit exists in the Rust port.
2. Multipart filenames that aren't valid UTF-8 are decoded with U+FFFD replacement characters.
   Rails keeps the raw bytes in a UTF-8-tagged string.
3. Charsets: only UTF-8, US-ASCII and ISO-8859-1 are transcoded, for `text/plain; charset=` fields
   and for `filename*`. Other charsets Ruby knows, such as Windows-1252 or ISO-2022-JP, are treated
   as binary (text fields) or as UTF-8 (filenames).
4. `_method` is read from the Rails-built params. Rack builds them with its own `QueryParser`,
   which differs from Rails only on malformed nesting.
5. Permit filters cover the shapes Campfire uses (keys, `[]`, `{}`, nested arrays and hashes,
   fields_for-style hashes). Hash-style filters with numeric keys, and `expect`, are not ported.
