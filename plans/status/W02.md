## Notes for dependents

- A controller derives from `ApplicationController` and builds its chain the way a Rails class
  body reads: `static readonly ControllerCallbacks<RoomsController> Chain =
  Callbacks.For<RoomsController>().Before("set_room", c => c.SetRoomAsync(), only: ["show"])`,
  then `public static readonly RequestDelegate Show = Action(Chain, async c => ...)`, bound in a
  `Routes` hook (W01). `tests/Campfire.Web.Tests/Pipeline/MatrixControllers.cs` has worked examples.
- `ControllerCallbacks` follows `ActiveSupport::Callbacks`: `only`/`except`/`if`/`unless`,
  re-declaring a named callback moves it to the end, skipping with conditions keeps it with
  inverted conditions, skipping a missing callback throws, a callback that renders or redirects
  halts the chain, and after callbacks run in reverse. `RescueFrom` is `rescue_from`.
- Concern declarations are extension methods: `AllowUnauthenticatedAccess`, `AllowBotAccess`,
  `RequireUnauthenticatedAccess`, `SkipForgeryProtection`, `EnsureCanAdminister`.
  `RoomScoped.FindRoomAsync` is `set_room`; `RememberLastRoomVisited`/`LastRoomVisitedAsync` are
  TrackedRoomVisit.
- `Current` (`controller.Current`) carries the account, user, session and request.
  `CookieSession`, `Flash`, `Cookies` (signed, encrypted and permanent jars), `RedirectTo` with
  flash, `RespondTo`, `Head`, `FreshWhen`/`IsStale`/`HttpCacheForever`, Rack::ETag,
  ConditionalGet, Head and Deflater, `RemoteIp` and `RequestUrl` live in `src/Campfire.Web/Pipeline/`.
- The `sessions/incompatible_browser` page is A01's: implement the
  `ApplicationController.IncompatibleBrowserPage` partial hook. Until then a blocked browser gets 501
  (the matrix compares only status and cookies for that case).
