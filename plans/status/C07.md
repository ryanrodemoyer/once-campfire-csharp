## Notes for dependents

`src/Campfire.RailsCompat/UserAgent/` (namespace `Campfire.RailsCompat.UserAgent`):

- `ParsedUserAgent.Parse(string?)`: the useragent gem 0.16.11, ported from
  `reference-rust/crates/campfire/src/concerns/user_agent.rs`.
- `ApplicationPlatform(string? userAgent)`: `reference/app/models/application_platform.rb`, what
  `SetPlatform#platform` builds from `request.user_agent`. `IsChrome()`, `IsFirefox()`,
  `IsSafari()`, `IsEdge()`, `IsWindows()`, `OperatingSystem()` and `Browser()` are methods because
  they can throw `GemRaisedException` where Rails raises (a nil gem `browser`, a Podcast Addict
  agent without a device comment, and so on). Rails answers those requests with a 500; W02 should
  let the exception reach the same error handling rather than swallow it.
- `AllowBrowser.IsBlocked(string? userAgent)`: `BrowserBlocker#blocked?` with Campfire's
  `{ safari: 17.2, chrome: 120, firefox: 121, opera: 104, ie: false }`. A blocked request renders
  `sessions/incompatible_browser`. `IsBlocked(ParsedUserAgent)` reuses a platform's parse.
- `tests/Campfire.RailsCompat.Tests/Campfire.RailsCompat.Tests.csproj` now references
  `tests/Campfire.Vectors` for the typed vector loader (a one-line wiring change to an F02 path).
