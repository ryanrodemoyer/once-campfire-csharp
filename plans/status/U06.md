## Notes for dependents

- `WebPushConnections` in `Campfire.Jobs.WebPush` manages pooled TLS connections to push endpoints. `WebPushClient` exposes `Connections` for sharing across deliveries, and `WebPushPool` shuts it down when disposed.
- `MessageViews.Load` now batch-loads attached blobs, their variant records, and video preview attachments across messages in constant queries, preventing N+1 queries on message lists.
- `UnfurlLinksController.Deadline` defaults to 10 seconds, with an optional per-app override `WebApp.UnfurlDeadline`.
- `OpenGraphFetch.DefaultTimeout` defaults to 7 seconds, with an instance property `OpenGraphFetch.Timeout`.
- `NamedVariants.ThumbnailMaxPixels` defaults to 250,000,000 pixels, with an optional per-app override `WebApp.ThumbnailMaxPixels`.
- Rich text file embeds render via `AttachmentPartials.RenderBlob` without generating previews on view, formatted using Rails-equivalent `HumanSize`.
