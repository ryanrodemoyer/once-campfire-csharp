## Notes for dependents

- `MessageAttachmentLifecycle.DestroyWithAttachment` now provides an overload taking `IJobQueue jobs` in addition to `IAppSeams seams`.
- `RemoveBannedContent` now takes `IJobQueue jobQueue` and `IClock clock`, enqueuing purge jobs for removed message attachments.
- Controllers attaching avatars/logos (`BlobStorage.AttachOne`) automatically enqueue `AnalyzeBlobJob` on transaction commit if `!attached.Blob.IsAnalyzed`.
- `CookieJar.Delete` no longer removes previous Set-Cookie entries from `setCookies`, allowing both Set-Cookie and deletion headers to be emitted in order as Rails does.
