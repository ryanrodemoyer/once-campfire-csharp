## Notes for dependents

- Register the channel with the cable server (P01 still owns the mount in `ServerCommand`):
  `.Channel(TurboStreams.ClassName, () => new TurboStreamsChannel<User>(keys))`.
  `TurboStreams.ClassName` is `"Turbo::StreamsChannel"`. The constant and
  `TurboStreams.VerifiedStreamName` live on the non-generic `TurboStreams` type.
- `SubscribedAsync` verifies `params[:signed_stream_name]` (`TurboStreamName`, salt
  `turbo/signed_stream_verifier_key`). A missing or JSON `null` name is unverified and rejected.
  Any other non-string throws, as `MessageVerifier#verified` does. A verified name whose
  `split(":", 2)` second part is `"messages"` is rejected (`RoomStreams.IsGuarded`), member or
  not. Anything else, including a verified empty name, is `StreamFrom`'d.
- Room message delivery is RT03's `RoomMessagesChannel` under `src/Campfire.Cable/Channels/`.
  The stream name is the room GID param (`GlobalId.Create(model, id).ToParam()`) joined with
  `:messages`. Use `RoomStreams.IsGuarded` and `TurboStreams.VerifiedStreamName`, then
  `Memberships.FindFor`, then `StreamFrom`. The golden-replay stand-in in
  `GoldenReplayTests` stays; it is not this channel.
- `TurboBroadcasts.Append`, `Replace`, and `Remove` (`src/Campfire.Web/Broadcasts/TurboBroadcasts.cs`)
  render the `<turbo-stream>` tag and JSON-encode it the way Action Cable's default coder encodes
  a string (`RailsJson.Encode` of the HTML string), then call `IBroadcaster.Broadcast`. Blank
  streamable parts are dropped; if none remain, nothing is sent. Extra replace attributes
  (`maintain_scroll`) are written before `action`. `WriteController` (M05) already broadcasts
  create, replace, and remove with the same encoding and was left as it is.

  `in-progress` or `needs-human` label, so the orchestrator can claim them.
