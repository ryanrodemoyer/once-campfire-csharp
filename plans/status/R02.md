## What was built

- **Allowlists and Configuration** (`SafeList.cs`):
  - Full tag and attribute allowlists matching `Rails::HTML5::SafeListSanitizer`, `ActionText::ContentHelper`, `ContentFilters`, and `auto_link`.
  - Presets: `SafeList.Defaults`, `SafeList.ActionText`, `SafeList.ContentFilter`, `SafeList.AutoLink`, and `SanitizeTagsAllowedTags`.
- **SafeList Sanitizer** (`SafeListSanitizer.cs`):
  - Permit scrubber ported from Loofah / Rails HTML5 sanitizer.
  - Unwraps disallowed tags while preserving children.
  - Scrubs disallowed attributes.
  - Protocol allowlisting (`AllowedUri`) supporting RFC 3986 safe schemes and safe data media types.
  - CSS style scrubber allowing `color`, `background-color`, and `white-space` with plain colors, rgb/rgba/hsl/hsla, and `var(--...)`.
  - Libxml2 attribute escaping parity (`force_correct_attribute_escaping!` for spaces and quotes in `href`, `action`, `src`, and `name` on `<a>`).
  - Serializer with bracket-escaping (`<` and `>` in attribute values) for safe regex scanning by `auto_link`.
- **Ruby URI Parser** (`RubyUri.cs`):
  - Strict RFC 3986 URI parsing matching Ruby's `URI.parse` and `URI::Generic` normalization.
- **OpenGraph Embed URL Constraints** (`OpengraphEmbedUrl.cs`):
  - `WebUrl` constraint validator matching Campfire's `WebUrl` / `ValidHost` logic, isolating request host and rejecting IP addresses.
- **Content Filters Pipeline** (`ContentFilters.cs`):
  - Full implementation of `ContentFilters::TextMessagePresentationFilters`:
    1. `CanonicalizeContent`: parses trix attachments (`data-trix-attachment` and `data-trix-attributes`) with JSON comment tolerance, empties inner HTML of attachments, and canonicalizes gallery `div` wrappers.
    2. `RemoveSoloUnfurledLinkText`: normalizes tweet URLs (`x.com` to `twitter.com`, stripping query params) and strips solo unfurled URLs matching message text.
    3. `SanitizeTags`: strips disallowed elements together with their entire subtrees.
    4. `SanitizeAttributes`: safe-list attribute scrubbing with `SafeList.ContentFilter`.
- **AutoLink** (`AutoLink.cs`):
  - Port of `rails_autolink` 1.1.8 with `TagIndex`, URL / email parsing, bracket balancing, punctuation stripping, and re-sanitization via `SafeList.AutoLink`.

## Notes for dependents

- R03 (Rich text attachables) will consume `CanonicalizeContent` and the attachment node definitions to resolve SGIDs, render attachments into `<action-text-attachment>` inner HTML, and format gallery wrappers (`attachment-gallery--{n}`).
- `ContentFilters.ApplyTextMessagePresentationFilters(html, requestHost)` is available as the complete presentation filter for incoming and outgoing rich text messages.
- `SafeListSanitizer.Sanitize` and `SafeListSanitizer.SanitizeWithEscapedAttributeBrackets` provide standalone HTML sanitization for any custom safe lists.
