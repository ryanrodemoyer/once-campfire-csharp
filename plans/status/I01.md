## Notes for dependents

- `Campfire.Jobs.Runner.JobRunner` implements `IJobQueue`. Build `DomainSeams` with it as `Jobs`.
  Register each job type before the app takes requests:
  `runner.Register<PushMessageJob>(perform, new JobQueueLimits(Capacity, Concurrency))`.
  Defaults: capacity 1024, concurrency 1. A type without a handler is logged and dropped.
- `Enqueue` never blocks and never runs the job on the caller's thread, so it's safe inside a
  write transaction (where `UserLifecycle.Ban` calls it) and in after-commit callbacks. It
  enqueues at once, not after the commit: Rails enqueues to Resque right away
  (`enqueue_after_transaction_commit` is false, see `IJobQueue`). Message jobs already come from
  after-commit callbacks in Lifecycle.
- A job that throws is logged with its exception and discarded, as Resque does. ApplicationJob
  doesn't `retry_on`.
- Logging goes through the `JobLog` delegate `(level, message, exception)`. The server (P lane)
  adapts it to its `ILogger`. The server should call `ShutdownAsync(deadline)` when the app
  stops, after the HTTP server stops taking requests and before `SqliteDatabase.Dispose`.
  `DisposeAsync` uses a 25s deadline.
- `RemoveBannedContent(database, broadcaster, clock).RegisterWith(runner)` performs
  `RemoveBannedContentJob`. It reads `user.messages`, then destroys each message in its own
  write transaction through `MessageLifecycle.Destroy`, and after that commit broadcasts
  `broadcast_remove_to room, :messages`: `<turbo-stream action="remove"
  target="message_<client_message_id>"></turbo-stream>`, JSON-encoded, on
  `<room to_gid_param (STI class)>:messages`.

## Known gaps

- `MessageLifecycle.Destroy` (Data lane, D03) handles only messages without an attachment. A
  banned user's message with a file keeps its `active_storage_attachments` row, and nothing
  enqueues the blob's `ActiveStorage::PurgeJob`. M05's message destroy needs the same
  attachment-aware destroy, and this job will pick it up once `MessageLifecycle.Destroy` does
  it. Raised on #30.
