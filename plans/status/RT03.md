## Notes for dependents

- Register every Campfire channel with `AppChannels.Register(builder, database, keys)`
  (`src/Campfire.Cable/Channels/AppChannels.cs`). It registers `ApplicationCable::Channel`
  (`EmptyChannel<User>`), `HeartbeatChannel`, `PresenceChannel`, `ReadRoomsChannel`,
  `RoomChannel`, `RoomMessagesChannel`, `TypingNotificationsChannel`, `UnreadRoomsChannel`, and
  `Turbo::StreamsChannel`. RT04 and P01 should call this when `/cable` is mounted. The builder
  is returned for chaining.
- Room subscriptions cast `params[:room_id]` with `RoomIds.Cast` and stream for the room GID of
  the STI class (`gid://campfire/Rooms::Open/<id>` and the closed and direct equivalents) via
  `RoomSubscription.GidParam`. A user who is not a member is rejected.
- `RoomMessagesChannel` verifies `signed_stream_name` with the same key as
  `Turbo::StreamsChannel`, then allows only a `:messages` suffix whose GlobalID locates a room
  the current user belongs to. A guarded name on `Turbo::StreamsChannel` is still rejected
  (RT02).
- Presence calls `Memberships.Present`, `Memberships.Disconnected`, and
  `Memberships.RefreshConnection`, and reads `CableServer.Clock` at call time. `present` also
  broadcasts `{"room_id":N}` on `ReadRoomsChannel.StreamNameFor` (`user_<id>_reads`).
- Unread fanout for a posted message is `UnreadRoomsChannel.BroadcastUnread(broadcaster, session, roomId)`:
  encode `{"roomId": id}` once with `RailsJson.Encode`, then `IBroadcaster.Broadcast` (`coder: nil`)
  to each plucked member. Performing `subscribed` while already subscribed adds a second stream,
  so one broadcast is delivered twice, matching the golden.
