## Notes for dependents

- `UsersAutocompletablesTemplate` (`Views/users/autocompletables/`) is the real autocomplete pill.
  M07's `UsersAutocompletablesTemplateStandIn` under `Views/rooms/directs/` renders the same bytes
  and can be removed.
- The manifest builds `/account/logo?size=small&v=` itself. `Routes.FreshAccountLogoPath` writes
  `v` before `size`, which is not what `route_for` does in this template.
- `GET /up` is `RailsHealthController` (`ActionController::Base`): no authentication, no browser
  block, no `X-Version`. HTML is the green doctype string; JSON is
  `{"status":"up","timestamp":...}` from `Time.current.iso8601`.
- Autocomplete requires a signed-in user, twenty per page. JSON sets `X-Total-Count` and `Link`
  unless the page is the last one. A page past the end is not the last.
