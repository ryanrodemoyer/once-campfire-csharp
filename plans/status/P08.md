## Notes for dependents

- **Running it locally**: `tests/image-smoke/run.sh [IMAGE]` builds the root Dockerfile (default tag
  `campfire-csharp:smoke`), starts it with `parity/.env.reference` on an empty scratch storage
  directory, and runs `tests/image-smoke/smoke.mjs` against it. It needs Docker and Node 24 (the
  driver uses the built-in `fetch` and `WebSocket`, with no dependencies).
- **CI**: `.github/workflows/image.yml` checks out with submodules (the Dockerfile copies
  `reference/`) and sets up Node 24, then runs `tests/image-smoke/run.sh`.
- **Environment**: the reference's test keys in `parity/.env.reference`. They're test-only, as the
  file says.
