## Notes for dependents

- `WebApp.Responses` is the page cache (`Campfire.Web.ResponseCache.ResponseCache`) and `WebApp.Fragments` is the 64 MiB fragment store. Both are per app, created on first use. `CAMPFIRE_RESPONSE_CACHE_MB` (default 64, `0` disables) is read on each budget check. `0` disables completed-page admission only. Fragment reads and the broken-room 500 still run whenever the captured `data_version` is current.
- Version is `PRAGMA data_version` on a read-only connection, captured in a prepended before (`CachedResponses`) ahead of authentication. Lookup and admission both require that same version. `ResponseCache.Clear` drops the observer, so the next version uses a new namespace and epoch-keyed fragments miss. Content keys (`FragmentRendering`, message bodies whose creator and boosts are loaded) omit the epoch.
- Room show, messages index, sidebar, and search wrap their actions in `CacheReadResponseAsync`. A hit still authenticates and authorizes. Stored headers are Content-Type, Content-Encoding, Cache-Control, ETag, Last-Modified, and Vary. Gzip and identity are separate entries; `RackDeflater.GzipBody` is the stored gzip.
- `RecordSnapshots.RoomAsync` / `MembershipAsync` / `SessionAsync` share `FragmentStore`. `SessionLookup` stashes the snapshot user on `RecordCachedUser` for `Authentication`. `SqliteSession.QueryListener` is an `AsyncLocal` around `Command`.
- Q11 still owns the `Link` header, charset case, Turbo Frame layout, and avatar `X-Rev`/`X-Version`. The involvement flash above is that Turbo Frame layout consuming a session flash.
- B07 can treat a cache-on room, messages, sidebar, or search response as replay-equal to Rails. Budget 0 on the candidate alone changes `Vary` order on those pages to the deflater's order.
- `response_cache_key` strings go through `ActiveSupport::JSON.encode` as this app boots it. Checked in `campfire-reference:edbc779`: `escape_html_entities_in_json` is true and `escape_js_separators_in_json` is false (`config.load_defaults 8.2`). `<`, `>` and `&` expand to `\u003c`, `\u003e` and `\u0026`, which is what moves a long URL or user agent across the 2 KiB key cap. U+2028 and U+2029 stay raw. The gem default is the opposite for the separators; the railtie copies the load_defaults flag before encode.
- `WebApp.Responses` and `WebApp.Fragments` are published with `Interlocked.CompareExchange`, so two first requests share one store. `Reads` and `Writes` use `Interlocked.Increment`.
- Files outside `owns` are the wiring the page cache has to touch. Comments on the owning issues are listed in the pull request. `plans/status/U07.md` is this task's own status file.
