## What was built

- `MessagesIndexController` (`Controllers/Messages/Index*`): `messages#index` with `layout
  false`. `before` pages with `MessagePages.PageBefore`, `after` with `PageAfter`, otherwise
  `LastPage`. An empty page is `head :no_content` before format negotiation. A non-empty page
  calls `fresh_when` on the message cache keys, including the index template digest only when
  HTML is negotiated, then renders `messages/index` or raises `UnknownFormat`.
- `RoomsRefreshesController` (`Controllers/Rooms/Refreshes*`): `rooms/refreshes#show`. `since`
  is `Time.at(0, params[:since].to_i, :millisecond)`. New messages are
  `PageCreatedSince`; updated messages are `PageUpdatedSince` excluding those ids. The response
  is `show.turbo_stream` (`text/vnd.turbo-stream.html`). An empty pair still renders (a single
  newline). HTML-only `Accept` is 406.
- `Views/messages/index.html.erb.cs` renders the message collection. `Views/rooms/refreshes/`
  appends new messages onto `messages_<room dom id>` and replaces each updated message.

## Notes for dependents

- **B02** can measure `GET /rooms/486777696/messages?before=933434569` as David. The cold-cache
  body matches the reference once CSRF tokens are normalized, and the ETag above is stable.
  Refresh has no `fresh_when`; its ETag is Rack's body digest.

  (M03). `room_not_found` is the create rescue in M05; index and refresh raise
  `RecordNotFound` (404) when the user is not in the room.

  That file is outside this task's `owns` and was not edited.

## Known gaps

- **Fragment caching** (M02): the reference caches each `_message` fragment, so a later render
  of the same messages reuses the first request's CSRF tokens and does not write
  `_campfire_session`. This port renders every time, so those tokens are new and a repeated
  page sets `_campfire_session`. The first render of each distinct page, including the
  acceptance path, matches cookies exactly.
