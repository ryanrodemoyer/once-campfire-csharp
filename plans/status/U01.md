## Notes for dependents

- **The parity clock must move.** Rails edbc779 won't boot with its clock before 2026-10-08
  (`InvalidMigrationTimestampError`), so `--time 2026-03-02T16:00:00Z` (the seed instant, used by
  `parity/screens/compare`, the vector generators and the README examples) fails. Use a later
  instant, e.g. `--time 2026-10-09T16:00:00Z`; Ruby vs Ruby replay is clean on it.
- **The replay and continuity harnesses need U03 first**: they raise when a page has no
  authenticity token, which is every Rails page now. The runs in upstream-sync.md used a local
  change to `parity/replay/replay.py` that sends a token only when the page has one.
- `parity/bin/reference` takes `PARITY_APP_IMAGE` (default `campfire-reference:app`) beside
  `PARITY_IMAGE`, so images for two pins can coexist.
- Ported in U01 because the asset rebuild needed it: Propshaft 1.3.2's `"app"` manifest flag
  (`AssetSources.AppPaths`) and ActionDispatch::Static's `charset=utf-8` on HTML and CSS.
- The Erubi golden for the template scanner was regenerated in the reference image; the command
  is in `tests/Campfire.Templates.Generator.Tests/Erubi/generate.rb`.
- `bench/bin/run`'s header comment also now points at `parity/bin/reference build`.
- On the seed, `rooms.messages_count` trails the real count in two rooms (fixtures load after the
  triggers); that is Rails' state (U02).
