# Golden vectors

Expected output generated by the reference Rails app, imported byte for byte from the Rust port
(`reference-rust/`, pinned to `basecamp/once-campfire-rust@ccece30`). Never edit these files by hand.
[`MANIFEST`](MANIFEST) records each file's SHA-256 and its source path in `reference-rust/`, and
`tests/Campfire.Vectors/Tests/ManifestTests.cs` checks both on every `bin/check`.

| File | Generator (`reference-tools/`) | What it pins |
| --- | --- | --- |
| `rails_compat.json` | `rails_compat_vectors.rb` | key generator, signed/encrypted cookies, session and CSRF, signed ids, GlobalID/SGID, Turbo stream names, app verifiers, bcrypt |
| `ruby_core.json` | `ruby_core.rb` | Ruby string coercion and escaping, `Float#to_s`, Rack byte ranges |
| `campfire_routes.json` | `campfire/routes.rb` | route table and recognition |
| `campfire_sessions.json` | `campfire/session_cookies.rb` | seeded session cookies and signed blob ids |
| `campfire_user_agents.json` | `campfire/user_agents.rb` | `useragent` gem and `ApplicationPlatform` |
| `storage.json`, `storage/` | `storage/generate.rb` | Active Storage keys, variations, Marcel, filenames, variant bytes |
| `richtext/` | `richtext/generate.rb` | rich text presentation, plain text, editable body, mentions |
| `opengraph/` | `oracle/opengraph.rb` | Opengraph unfurling against scripted servers |
| `webhook/` | `oracle/webhook.rb` | bot webhook requests and replies |
| `rqrcode.json` | `campfire/rqrcode.rb` | RQRCode matrices and SVG |

The Rails-generated files use the fixed `SECRET_KEY_BASE` from the Rust port's
`parity/.env.reference` (recorded as `secret_key_base`) with the clock frozen at `now`
(2026-01-01T12:00:00Z).

## Using them in tests

Reference `tests/Campfire.Vectors/Campfire.Vectors.csproj` and pass a family to a theory:

```csharp
[Theory]
[MemberData(nameof(RailsCompatVectors.SignedCookieVerify), MemberType = typeof(RailsCompatVectors))]
public void VerifiesRailsSignedCookies(SignedCookieVerify vector) { ... }
```

Each family is a static method returning `TheoryData<T>` with one named row per case; the whole
file is available as a typed record through the class's `File` property (or `*File` for classes
covering several files).

## Updating

    git -C reference-rust checkout <sha> && reference-tools/import.sh

re-copies every vector and rewrites `MANIFEST`. Regenerating them from the reference app directly
is task V01.
